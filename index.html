Exercice 6 : Entité C2_3 & Instruction case ... when

1. Rappel de l'Énoncé

Données de l'exercice

Écrire le code VHDL, l'entité et l'architecture selon la description suivante :

Nom de l'entité : C2_3
Architecture : A2_3
Signaux d'entrée : x0, x1 (std_logic)
Signal de sortie : z (std_logic)
Fonctionnement demandé :

En utilisant case when, le signal de sortie z doit être assigné selon la table de vérité ci-contre. Tous les états non spécifiés des signaux d'entrée doivent donner lieu à l'assignation de la valeur zéro ('0') au signal de sortie z.

Table de Vérité de l'Énoncé

'0' '0' "00" '1'

'1' '1' "10" '1'
'1' '1' "11" '1'
États non spécifiés ('U', 'X', 'Z', 'W', 'L', 'H', '-') '0'
Vérification Algébrique (Équation avec barre) :

• Somme des mintermes : Z = (x0 · x1) + (x0 · x1) + (x0 · x1)
• Par De Morgan sur l'unique zéro (Z = x0 · x1) : Z = x0 + x1

Ma Démarche de Résolution

2. Explications & Justification de mes Choix en VHDL

Analyse Personnelle Détaillée
01

Pourquoi ai-je utilisé un process(x0, x1) ?

Dans les exercices 2 et 3 du TD, on utilisait with ... select et when ... else qui sont des instructions concurrentes (elles s'écrivent directement dans l'architecture). Ici, l'énoncé impose d'utiliser case ... when. Or, en VHDL, case est une instruction strictement séquentielle.

→ Ma solution : J'ouvre un bloc process(x0, x1) en mettant bien x0 et x1 dans la liste de sensibilité pour que la sortie z soit recalculée dès qu'une entrée change.
02

Astuce de concaténation (x0 & x1)

Au lieu d'imbriquer deux case l'un dans l'autre (un pour x0 puis un pour x1, ce qui alourdit le code), j'ai choisi de regrouper les deux signaux en un seul vecteur de 2 bits grâce à l'opérateur de concaténation &.

→ Précaution de compilation : J'ai déclaré une variable locale sel : std_logic_vector(1 downto 0); affectée par sel := x0 & x1; pour que le compilateur VHDL connaisse exactement les bornes du vecteur testé.

03

Pourquoi when others => z <= '0'; est indispensable ?

Les entrées x0 et x1 ne sont pas de type bit (qui n'a que '0' et '1'), mais de type std_logic (norme IEEE 1164) qui possède 9 états : 'U', 'X', '0', '1', 'Z', 'W', 'L', 'H', '-'.

Avec 2 entrées à 9 états, il y a 9 × 9 = 81 cas possibles. La table n'en spécifie que 4 ("00", "01", "10", "11"). La ligne when others => z <= '0'; traite d'un seul coup les 77 états non spécifiés restants comme exigé par l'énoncé.
04

Simplification Booléenne avec Barres d'Inversion

En observant la table de vérité, on remarque que Z = '1' pour trois lignes et Z = '0' pour une seule ligne (x0 = 0 et x1 = 1) :

Z = x0 · x1
⇒ Z = x0 · x1 = x0 + x1 (Théorème de De Morgan)

-- Je déclare la bibliothèque IEEE et le paquetage std_logic_1164
-- afin de pouvoir utiliser le type à 9 états "std_logic" demandé dans l'énoncé.
library IEEE;
use IEEE.std_logic_1164.all;

-- Déclaration de l'entité C2_3 avec ses deux entrées x0, x1 et sa sortie z
entity C2_3 is
    port (
        x0, x1 : in  std_logic;  -- Signaux d'entrée de type std_logic
        z      : out std_logic   -- Signal de sortie de type std_logic
    );
end C2_3;

-- Déclaration de l'architecture A2_3 associée à l'entité C2_3
architecture A2_3 of C2_3 is
begin

    -- Attention : comme l'instruction "case ... when" est séquentielle,
    -- je dois obligatoirement la placer à l'intérieur d'un process.
    -- Je mets x0 et x1 dans la liste de sensibilité pour réévaluer z à chaque changement.
    process(x0, x1)
        -- Astuce : je déclare une variable locale de 2 bits pour regrouper x0 et x1
        -- et tester directement les 4 lignes de la table de vérité.
        variable sel : std_logic_vector(1 downto 0);
    begin
        -- Je concatène x0 et x1 avec l'opérateur '&' (affectation immédiate ':=' car c'est une variable)
        sel := x0 & x1;

        -- Test des combinaisons selon la table de vérité de l'exercice
        case sel is
            when "00" =>
                z <= '1';  -- 1ère ligne : x0 = '0' et x1 = '0' ==> z = '1'

            when "01" =>
                z <= '0';  -- 2ème ligne : x0 = '0' et x1 = '1' ==> z = '0'

            when "10" =>
                z <= '1';  -- 3ème ligne : x0 = '1' et x1 = '0' ==> z = '1'

            when "11" =>
                z <= '1';  -- 4ème ligne : x0 = '1' et x1 = '1' ==> z = '1'

            -- Je n'oublie surtout pas "when others" demandé par l'énoncé :
            -- si x0 ou x1 prend un état non spécifié ('U', 'X', 'Z', 'W', 'L', 'H', '-'),
            -- la sortie z est immédiatement forcée à '0'.
            when others =>
                z <= '0';
        end case;
    end process;

end A2_3;
-- ============================================================================
-- USTHB - Master FGE | TD N°1 : Exercice 6 (Seconde écriture plus compacte)
-- Réalisé par : Dahane Ahmed Lamine
-- Idée : Je regroupe les cas où z = '1' avec la barre de choix '|'
-- ============================================================================

library IEEE;
use IEEE.std_logic_1164.all;

entity C2_3 is
    port (
        x0, x1 : in  std_logic;
        z      : out std_logic
    );
end C2_3;

architecture A2_3 of C2_3 is
begin

    process(x0, x1)
        variable sel : std_logic_vector(1 downto 0);
    begin
        sel := x0 & x1;

        case sel is
            -- Les trois combinaisons "00", "10" et "11" donnent toutes z = '1'
            when "00" | "10" | "11" =>
                z <= '1';

            -- Tous les autres cas (le cas "01" ainsi que les états non spécifiés) donnent z = '0'
            when others =>
                z <= '0';
        end case;
    end process;

end A2_3;

Exercice 7 : Entité C2_4 & Porte XOR à 3 Entrées

1. Rappel de l'Énoncé

Données de l'exercice

Écrire le code VHDL, l'entité et l'architecture selon la description suivante :

Nom de l'entité : C2_4
Architecture : A2_4
Signaux d'entrée : x0, x1, x2 (std_logic)
Signal de sortie : z (std_logic)
Spécification fonctionnelle :

Le signal de sortie z doit être assigné à la valeur d'une porte XOR (OU Exclusif) à 3 entrées (x0, x1 et x2).

2. Mon Analyse Logique & Équations avec Barre

A. Associativité de l'opérateur OU Exclusif (⊕)

Comme l'opérateur xor est associatif, une porte XOR à 3 entrées équivaut à mettre deux portes XOR à 2 entrées en cascade :

Z = x0 ⊕ x1 ⊕ x2 = (x0 ⊕ x1) ⊕ x2
B. Fonction de Détecteur de Parité Impaire

En dressant la table de vérité à 8 lignes, j'ai vérifié un point important : la sortie Z vaut '1' lorsque le nombre d'entrées égales à '1' est impair (c'est-à-dire quand une seule entrée est à '1', ou quand les 3 entrées sont à '1' simultanément car (1 ⊕ 1) ⊕ 1 = 0 ⊕ 1 = 1).

C. Développement Canonique (Somme des Mintermes avec Barres)

Z = (x0 · x1 · x2) + (x0 · x1 · x2) + (x0 · x1 · x2) + (x0 · x1 · x2) = ∑ m(1, 2, 4, 7)

-- Appel de la bibliothèque IEEE pour utiliser le type std_logic
library IEEE;
use IEEE.std_logic_1164.all;

-- Déclaration de l'entité C2_4 : 3 entrées (x0, x1, x2) et 1 sortie (z)
entity C2_4 is
    port (
        x0, x1, x2 : in  std_logic;  -- Les 3 entrées de la porte XOR
        z          : out std_logic   -- La sortie logique z
    );
end C2_4;

-- Déclaration de l'architecture A2_4 en description "Flot de données" (concurrente)
architecture A2_4 of C2_4 is
begin

    -- Ici je n'ai pas besoin de process car c'est une simple équation combinatoire.
    -- Grâce à l'associativité du OU Exclusif, j'enchaîne directement l'opérateur "xor"
    -- entre les trois entrées x0, x1 et x2.
    z <= x0 xor x1 xor x2;

end A2_4;
-- ============================================================================
-- USTHB - Master FGE | TD N°1 : Exercice 7 (Seconde méthode par décomposition)
-- Réalisé par : Dahane Ahmed Lamine
-- Idée : J'utilise un signal intermédiaire pour représenter le câblage
--        de deux portes XOR à 2 entrées mises en cascade.
-- ============================================================================

library IEEE;
use IEEE.std_logic_1164.all;

entity C2_4 is
    port (
        x0, x1, x2 : in  std_logic;
        z          : out std_logic
    );
end C2_4;

architecture A2_4 of C2_4 is
    -- Je déclare un signal interne s_int (avant le begin) pour relier
    -- la sortie de la première porte XOR à l'entrée de la seconde.
    signal s_int : std_logic;
begin

    -- 1ère porte XOR : calcul de x0 xor x1
    s_int <= x0 xor x1;

    -- 2ème porte XOR : calcul du résultat précédent avec la 3ème entrée x2
    z     <= s_int xor x2;

end A2_4;
